Install the JavaScript SDK
Connect your app to LaunchDarkly. You'll create your first flag right after.
Environment: Production ▾
Language: React ▾
Package manager: npm ▾
1 Install the SDK
npm install launchdarkly-react-client-sdk @launchdarkly/observability @launchdarkly/session-replay
Also set up Observability and Session Replay ✓ Included in your plan
Errors, logs, traces, and session replays, tagged with the flag variations each user saw. Adds two packages and one config block to the same file you're already editing. Replays mask text and inputs by default.
2 Initialize the client
import { asyncWithLDProvider } from 'launchdarkly-react-client-sdk'; + import Observability from '@launchdarkly/observability'; + import SessionReplay from '@launchdarkly/session-replay'; const LDProvider = await asyncWithLDProvider({ clientSideID: '<your-client-side-id>', context: { kind: 'user', key: 'example-user' }, + options: { plugins: [new Observability(), new SessionReplay({ privacySetting: 'strict' })] }, });
3 Run your app
We'll confirm here the moment we see a connection, and light up Errors, Sessions, and auto-created error-rate metrics.
