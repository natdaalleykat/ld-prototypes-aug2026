What does not change your bill
  • The Relay Proxy or daemon mode. We count the SDKs behind the proxy, not the proxy. Neither changes your count or your rate.
  • How many flags you have, or how often you evaluate them. 10 flags and 10,000 flags cost the same. Backend requests do not count. The one exception is PHP, which polls instead of streaming: 732 polls a month equals 1 connection.
  • Pod size. CPU and memory do not count. How many copies run, and for how long, does.
  • Reconnects. A dropped stream that reconnects does not start a new charge. We only add up connected minutes. A rolling deploy counts the few minutes old and new copies overlap.
  • Your browser, mobile and edge SDKs. They never create a connection. Browser and mobile SDKs count as monthly active users.
Your first week after you buy
  • Set an application ID on every service. Otherwise your usage page says "Unknown" and you cannot see which service is using connections.
  • Point laptops and CI at the dev server. It serves flags from a local process, so those hours create no connections.
  • Create one SDK client per process, at startup. Not per request. Forked workers each need their own; threads in one process share it.
